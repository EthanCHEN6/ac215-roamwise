# Sharing RoamWise

Public app: https://roamwise-rag-74919420019.us-central1.run.app

The new release hosts the complete app on Cloud Run. Teammates can use its public HTTPS URL when the owner's computer is off. See `docs/DEPLOYMENT.md` and `evidence/cloud-deployment.json` for the deployed service.

The original Sites address remains a convenient frontend entry. Browser-local saved trips do not transfer automatically between domains or devices; use Export plan to share a text copy.

The old Cloudflare tunnel scripts and recorded retrieval examples are retained as historical project materials. The new RAG app does not require that tunnel.
